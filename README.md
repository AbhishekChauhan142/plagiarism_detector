# Plagiarism Detector - TF-IDF + S-BERT

Advanced plagiarism detection system using hybrid NLP techniques.

## Features

✅ **Dual Algorithm Detection**
- **TF-IDF**: Traditional lexical similarity (keyword matching)
- **S-BERT**: Semantic similarity (meaning-based detection)
- **Hybrid Scoring**: Combined weighted approach

✅ **Multiple Detection Modes**
- Interactive mode (2-document comparison)
- Batch mode (multiple documents)
- Demo mode (sample comparisons)

✅ **Comprehensive Reporting**
- HTML reports with statistics
- JSON format for integration
- CSV format for spreadsheet analysis

✅ **Dataset Support**
- Academic texts
- Plagiarism variants (direct, paraphrased, mosaic)
- Test pairs for validation
